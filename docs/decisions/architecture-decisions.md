# Architecture Decisions

## Browser First

RyzovaOS runs completely inside the browser.

---

## No Native Drivers

The browser is responsible for hardware communication.

---

## No Node.js Runtime

RVDE is designed to be browser-native.

---

## WebAssembly

Used for high-performance execution.

---

## OPFS

Persistent storage.

---

## Web Workers

Virtual CPU.

---

## SharedArrayBuffer

Virtual Memory.

---

## Modular Architecture

Every subsystem is replaceable.

---

## Security

Browser Sandbox.

---

## Long-term Goal

RVDE becomes a browser-native virtualization platform.

RyzovaOS becomes the flagship operating system built on RVDE.
